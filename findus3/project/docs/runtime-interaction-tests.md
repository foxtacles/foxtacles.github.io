# Original-script interaction checks

These checks run the supplied Director movies in the patched web runtime and use browser mouse/key input. VM reads inspect the original globals, sprite geometry, call stacks, and sound channels. They do not replace game logic or write gameplay variables.

Run the built web host on port 8766 before invoking the scripts from the project root. Screenshots and detailed JSON include the original VM state at each checkpoint.

The original launcher → calendar → each of the 24 days → calendar sequence also passes in a **single browser page and VM**, without reloads or direct movie loading between days. Door 16 follows the original redirect into KONSTR01. All 24 entry/return pairs had zero script errors, there were no browser errors, and all requested Director assets returned HTTP 200. This navigation test checks cleanup between activities; the gameplay tests below exercise their rules. See [the complete navigation report](../artifacts/runtime-tests/calendar-all-days/report.json) and its adjacent entry/return screenshots. Reproduce with `node runtime/dirplayer/calendar_all_days_probe.mjs`.

The normal construction completion tests wait for Pettson's final dialogue before returning. The separate [Construction 2 interruption test](../artifacts/runtime-tests/construction-interrupt/KONSTR02.json) also passes on the corrected runtime: a short Return tap delivered during the authored blocking dialogue is ignored after its physical release, because the original button handler checks `the mouseDown` before acting. The player remains responsive, the button state is released, and no Return handler is stuck; a subsequent fresh tap returns to the calendar. This does **not** claim that the first interrupted tap navigates. Reproduce with `FINDUS_INTERRUPT_DIALOG=1 node runtime/dirplayer/construction_probe.mjs KONSTR02`.

The fishing controller selects the rod position nearest the pan using read-only snapshots, then uses the original up-arrow action to damp the swing. The fish reaches the pan through the authored line physics. The construction order comes from the recovered placement rules and the parts' original target coordinates. Both snowboard slopes reach the authored finish; set `FINDUS_STEEP=1` to run the steep variant. Steering is intentionally ignored while the rider is airborne, matching the original script.

Audio has separate [sample-by-sample and three-engine verification](audio-runtime.md). These desktop Chromium gameplay checks alone do not establish behavior on physical phones or every browser engine.
